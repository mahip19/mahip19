### 🗄️ [Distributed File Storage (C++)](https://github.com/mahip19/Distributed-File-Storage-CPP)
A scalable, fault-tolerant file storage system built in **C++17** using POSIX sockets and OpenSSL.

`C++` `DHT` `Chain Replication` `SHA-256` `TCP` `Multi-threading`

- ⚙️ Consistent Hashing for data partitioning
- 🔗 Chain Replication (Head → Mid → Tail) for metadata consistency
- 🛡️ Replication factor of 2 with automatic failover
- 🧵 Custom thread pool for concurrent connections
